# أُفق (Ofok) — نظام إدارة الدروس الخصوصية والمراكز التعليمية

لوحة إدارة عربية متكاملة (`RTL`) للمعلمين والمراكز التعليمية لتنظيم شؤون الطلاب، الاشتراكات والإيصالات، الجدول الأسبوعي، ورصد الحضور والدرجات بدون أي تعقيد.

## المزايا الرئيسية

- **لوحة القيادة**: مؤشرات فورية للطلاب النشطين، الإيرادات الشهرية، الاشتراكات المستحقة للتجديد، والحصص القادمة مرتبة زمنياً.
- **إدارة الطلاب وملف الطالب**: تسجيل الطلاب، ربطهم بالمجموعات، متابعة الدرجات وسجل الحضور والمدفوعات، وتعديل البيانات مع تزامن فوري.
- **الاشتراكات والإيصالات**: دعم باقات متعددة ووسائل سداد متنوعة (نقدي، فودافون كاش، إنستاباي/تحويل)، مع نسخ الإيصال وإرساله لولي الأمر عبر واتساب.
- **الجدول الأسبوعي والمنسق التلقائي**: عرض بالبطاقات والخط الزمني، كشف التعارضات وهوامش الانتقال، ومنسق أسبوعي متوازن بضغطة واحدة.
- **الحضور والدرجات**: تسجيل الحضور والواجب والاختبارات، مع تحديث ذكي لكشف نفس اليوم دون خصم حصص مكررة.
- **النسخ الاحتياطي**: تصدير واستيراد كامل بصيغة `JSON` وتصدير جداول `CSV` متوافقة مع Excel.

## التشغيل محلياً

```bash
npm install
npm run dev
```

يعمل الخادم على المنفذ `3000` (`http://localhost:3000`).

## الأوامر المتاحة

- `npm run dev` — تشغيل بيئة التطوير
- `npm run lint` — فحص أنواع TypeScript
- `npm test` — تشغيل الاختبارات الأساسية لمنطق النظام
- `npm run build` — بناء نسخة الإنتاج داخل `dist/`
- `npm start` — تشغيل خادم الإنتاج

## النشر على GitHub Pages

المشروع مهيأ للعمل على روابط GitHub Pages الفرعية (`https://<user>.github.io/<repo>/`) عبر مسارات نسبية وملف تشغيل تلقائي `.github/workflows/deploy-pages.yml`.

لتفعيل النشر من إعدادات المستودع على GitHub:
1. افتح **Settings** ثم **Pages**.
2. في **Build and deployment → Source** اختر **GitHub Actions** (وليس `Deploy from a branch`).
3. بعد أي رفع على فرع `main` سيتم بناء المشروع ونشره تلقائياً على رابط GitHub Pages.
